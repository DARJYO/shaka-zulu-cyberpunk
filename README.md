## Overview

Trying to reimagine **Shaka Zulu** in a grounded 2026 African cyberpunk setting, merging traditional Zulu culture with cinematic realism, neon-lit futurism, and luxury UI design.
The experience feels like a Denis Villeneuve-directed interactive museum installation built in Africa. 

---

## Tech Stack

| Technology | Purpose |
|------------|---------|
| **Three.js** | 3D scene rendering, physically-based materials, realistic shadows |
| **GSAP + ScrollTrigger** | Cinematic scroll-driven animation timelines |
| **Lenis** | Smooth, inertia-based scrolling with gesture support |
| **Postprocessing** | UnrealBloomPass, RGBShift, AfterimagePass for filmic look |
| **Web Audio API** | Procedural ambient audio (deep drums, Afro-house textures) |
